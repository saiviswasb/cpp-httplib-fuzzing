# Coverage-Guided Fuzzing and LLM-Assisted Test Generation for cpp-httplib

Software Testing term project (solo). Fuzzes the parsers in
[cpp-httplib](https://github.com/yhirose/cpp-httplib) with AFL++, ASan and
UBSan. Measures whether seeds and dictionaries generated by an LLM
(Claude Code) improve coverage over hand-written and upstream ones.

## Reproduce

Everything runs on Linux (the lab machine). See [docs/machines.md](docs/machines.md).

```bash
git clone <this repo> && cd httplib-fuzz-lab
docker build -t httplib-fuzz -f docker/Dockerfile .
echo core | sudo tee /proc/sys/kernel/core_pattern   # host setting, once per boot
docker run --rm -it -v "$PWD":/work httplib-fuzz

# inside the container
scripts/fetch.sh                 # cpp-httplib at the pinned commit
scripts/build.sh                 # all targets: afl / plain / cov variants
scripts/smoke.sh server_fuzzer 60
```

Expected smoke output: `GO: N new inputs found`, plus an llvm-cov TOTAL line
for `httplib.h`.

## Pinned versions
See `scripts/versions.env`: cpp-httplib `bd23a7b` (0.65.0+), AFL++ v4.32c,
LLVM 18, Ubuntu 24.04.

## Layout
| Path | Contents |
|---|---|
| `docker/` | Reproducible toolchain image |
| `scripts/` | fetch, build, smoke, (later) campaign, coverage and plot scripts |
| `harness/` | Our harnesses and `cov_runner.cc` (coverage replay driver) |
| `corpora/`, `dicts/` | Arm A / B / C seeds and dictionaries |
| `results/` | Per-run summaries, coverage data, plots |
| `docs/` | Test strategy, AI process log, progress reports |

## Build variants
| Variant | Compiler | Flags | Used for |
|---|---|---|---|
| `out/afl/` | afl-clang-fast++ | `-fsanitize=fuzzer,address,undefined` | Fuzzing campaigns |
| `out/plain/` | afl-clang-fast++ | `-fsanitize=fuzzer` | afl-cmin |
| `out/cov/` | clang++ | `-fprofile-instr-generate -fcoverage-mapping` | Coverage measurement |
